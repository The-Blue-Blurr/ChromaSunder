# Attribution

ChromaSunder contains an independently maintained, modernized implementation
of pixel-sorting ideas derived from Satyarth's [Pixelsort project](https://github.com/satyarth/pixelsort).
Pixelsort was released under the MIT License. ChromaSunder is not an official
continuation, fork, or endorsed product of that project.

The original Pixelsort project and its contributors deserve prominent thanks
for making a practical Python implementation available to the community.

Kim Asendorf's [ASDFPixelSort](https://github.com/kimasendorf/ASDFPixelSort) work was
foundational inspiration for the pixel-sorting technique and for the original
Pixelsort project's direction. The reference link is retained here as a
historical attribution, not as an endorsement of ChromaSunder.
