# Chroma Sunder

Flutter application shell for Chroma Sunder V2. Full-resolution processing is provided by the
portable C++ engine through the handwritten Dart service in `packages/chromasunder_native`.

The MVP targets Linux, Windows, and Android. See `../docs/v2/DEVELOPMENT_ENVIRONMENT.md` for build
commands and `../docs/v2/ARCHITECTURE.md` for the native boundary.
